Remote Access Audit

Technician Quick Sheet — scan a PC for unauthorized remote-access software
Nerdy Neighbor
audit.nerdyneighbor.net

Run it

On the customer's PC, click Start, type PowerShell, open Windows PowerShell, then paste this line and press Enter:
irm audit.nerdyneighbor.net | iex
Click Yes on the User Account Control (UAC) prompt that appears. That's the only click needed to start. Windows 7 (needs WMF 5.1): [Net.ServicePointManager]::SecurityProtocol='Tls12'; irm audit.nerdyneighbor.net | iex

What happens

  1. Downloads the latest version automatically (nothing to install or update).
  2. Asks for Administrator rights once (UAC → Yes).
  3. Runs 14 scans (about 1 min; longer on big drives — let it finish).
  4. Opens the remediation window with every finding.
  5. Saves an HTML + JSON report to the Desktop when you close the window.

What it checks

Remote tools70+ tools: running, installed (Uninstall button), services, folders, downloaded installers
ScreenConnectfull removal incl. the LSA DLL that locks its folder
StartupRun keys (every user), Startup folders, scheduled tasks, WMI
BackdoorsSticky-Keys/Utilman swap, IFEO hijacks, Winlogon, AppInit, LSA
Filesunsigned programs hidden in AppData/Temp/ProgramData, fake svchost etc.
Networkremote/C2 ports, listening ports, suspicious outside traffic
AntivirusAV off/out of date, Defender + Security Essentials exclusions
SettingsRDP, Remote Assistance, WinRM, proxy/PAC, hosts file
Accountshidden accounts, Guest, new admin accounts

Reading the results

Each finding has a severity:
  • HIGH  Known remote tool or unsigned program in a hidden spot — investigate now.
  • MEDIUM  Suspicious but needs context (odd location, management port).
  • LOW  Worth a look — leftovers, adware, unsigned exe buried in AppData.
  • INFO  For reference: your own tools (SuperOps, OpenSSH), admin list.

Using the window

  • Fix buttons (e.g. Uninstall, Quarantine file, Remove startup entry) — say what they will do, ask once, then run right there. The card shows FIXED / FAILED + the result.
  • Details — paths, signer, command lines, and exactly what each fix does.
  • Fix all HIGH — runs the recommended fix for every HIGH item (one confirmation).
  • Rescan — checks again after fixing. Show: filter (needs attention / everything / fixed).
  • Nothing is deleted: files go to C:\ProgramData\NerdyNeighbor\RemoteAccessAudit\quarantine (renamed .quarantined); registry is exported to ...\backup first.
If a remote-access tool is confirmed and unauthorized:
  1. Disconnect the PC from the internet.
  2. Run the matching Fix / removal steps.
  3. Have the customer change passwords from a different device.
  4. Reboot if prompted (ScreenConnect DLL removal needs it).
Notes. Legitimate remote tools are reported too — confirm each one is authorized before removing. Report: Desktop\RemoteAccessAudit_<PC>_<date>.html (+ .json). Log: C:\ProgramData\NerdyNeighbor\audit.log. RMM / no window: $env:NN_AUDIT_MODE='report' before the irm line. Your own tools: $env:NN_AUDIT_TRUST='SuperOps,OpenSSH' (default).
